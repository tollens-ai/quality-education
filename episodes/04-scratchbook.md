> What changed your mind?

> Reload the screen; no sets are seen: we've lost the set we logged tonight.  
> We try once more, unlike before: connect, then save; the sets all stay.  
> We trace the clue; the check is new: it fails when records fade away.

**Bridge — crew, patter**

> Report the doubt, don't smooth it out; say what you skipped, and tell me why.

**Break — two voices, band stops**

> Testing: "What else should we know?"

**Refrain — all, word for word**

> Testing adds interpretation.  
> What did you try? What did you find?

**Outro — agent, spacious**

> Who sees the logs? That's still to do.

### Verified rhyme families, in General American

Every one of these was run through `music/check/rhyme.py`, which compares the phones from the
last primary stress onward, so "perfect" here means the tool found identical tails. The families
this song actually spends:

| /-ɔːt/ | thought, taught | v1 couplet 2 |
| /-ɛst/ | test it, guess it, second-guess it, press it | chorus couplet 1 |
| /-uːz/ | use it, prove it | chorus couplet 2 |
| /-oʊ/ | let it go, didn't know | chorus couplet 3 |
| /-oʊ/ | below, show, go, throw | v2 couplet 1, v2 couplet 3 |
| /-ænd/ | hand, understand | v2 couplet 2 |
| /-ɛn/ | again, then | v3 couplet 2 |
| /-ɔːr/ | for, lost | v3 couplet 3 |
| /-iːɪŋ/ | keeping, reading | bridge couplet 1 |
| /-ʌn/ | fun, undone | bridge couplet 2 |
| /-uː/ | do, true | break |
| /-iːn/ | green, machine | opening, outro |
| /-aɪ/ | why, try | outro |

Two families worth naming because they're large for this subject and weren't used here:
**/-ɛt/** (check, collect, connect, expect, correct, perfect, effect, tech, deck, reject,
inspect, protect, select, direct, set, get, yet, forget, regret, net, jet) and **/-aɪn/**
(sign, mine, design, line, decline, define, shine, confine, wine, nine, brine, twine). Note that
`defect` and `budget` do **not** join the /-ɛt/ family: the tool gives them tails `IY EH` and
`AH IH`. And *gone* is `G AO N`, so it does not rhyme with *on*, *home* or *go* — only with
*known*, *shown*, *own*, *alone*, *phone*.

### Rejected openings

Each of these was close and each failed for a different reason, so the reasons are the useful
part.

- **"I copy the code to the test, so the two of them nod in time / the test is the code in a
  costume; it only checks the sign."** The metaphor outran the joke. "Checks the sign" is not a
  phrase, and the image of the costume needed a second line to land.
- **"I let it mark its own homework"** — funny and accurate, but it wants a partner rhyme for
  *homework*, and the /-ɔːrk/ family is nearly empty (*work, word, world, worth* don't all hold
  *homework*). The "one hand wrote both" version got the same idea inside a closed couplet.
- **"The witness and the suspect share the same face, and it's me."** Detective gag, but *agree*
  and *me* are only a family rhyme, and the tool rejects it.
- **"I let the mirror up against a mirror."** The image is exact for a tautology and there is no
  rhyme. Parked for the storyboard, not the lyric.
- **"Thorough! Two hundred thorough checks — have I caught a thing? (Not once.)"** Kept, but
  *two hundred* twice in four bars was clumsy; the second one became *and I've been thorough
  about it*.

### Rejected teaching lines

- **"It only knows what changed. (What changed your mind?)"** was going to be the verse-1 refrain
  until *what changed your mind* turned out to be Qing's own line from an earlier chorus. Not
  borrowing it.
- **"Then tell me what you couldn't do."** The chorus couplet. It rhymes with *leads you*, but
  reads as a claim about capability. **"Tell me what you found, and what you didn't know"** says
  the same request and lands.
- **"Testing's finding out. (Who else knows?)"** wanted to state the Bach and Bolton definition
  outright. It's true and it's the credited source, but as a chorus tag it competes with the four
  questions, which are the part a viewer can act on. Left out; it belongs in the video's own
  text if anywhere.
- **"Let it hunt. There's more fun in that than in any test you'll throw."** Nearly cut as
  pointless. It's the only place the song says testing is *fun*, which Qing asked for twice, so
  it stays.

### The grid, and what fought it

The verse grid is **14 syllables, beat on 2, 4, 6, 8, 10, 12, 14**. It came out of the first
couplet — "the check is the code and the code is the check" happens to land one stressed syllable
on every even position — and was then held across the section.

Words that fight an even-syllable grid, because their stress falls between the beats:

- two-syllable words that can't be placed on the grid, whichever way round they go (*comma*,
  *paper*, *signal*, *playbook*, *understand*);
- **"playbook"** is stressed on *play*, so it wants the beat at syllable 7 where the grid wants
  8. Every other word in the line is fine. This is the one warning the checker raised.
- **"predicted"** is three syllables (*pre-dic-ted*), so it breaks a 14-syllable line wherever it
  lands. Rewrote the bridge around *couldn't predict*.
- Contractions are unusable with the checker (*hasn't* splits into two syllables, *there's* is
  missing from the dictionary). Rewrote around *has*, *will* and the full forms.

The practical lesson for whoever maps this: **write the first line of a couplet to the grid, then
make the second line's stress fall in the same fourteen slots.** It's the jigsaw in LYRICS.md, and
the checker turns "this scans" from an opinion into a measurement — but only if the marks say
what you intend, since the dictionary stresses every monosyllable and the capitals are the
writer's decision.
