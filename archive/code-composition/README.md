# Archived code-composition attempt

**Retired on 2026-09-30.** We did not produce melody, harmony and singing that met Qing’s bar
through the code-composition approach. Episode 1 ultimately shipped a MiniMax take;
episodes 2 and 3 used Suno. Claude is no longer asked to compose melody or harmony for this series.

This directory preserves the old [workflow](workflow.md), [music-craft notes](music-craft.md),
[toolchain](toolchain.md) and references for historical inspection. Their recipes and acceptance
rules are not validated current guidance. Some contain the overgeneralisation and correctness
problems identified during review; archiving them does not certify their claims.

The original code experiments remain in `music/ep01/`, `music/lib/` and `music/voice/`.
Use the current [songwriting skill](../../.claude/skills/songwriting/SKILL.md) for lyrics,
performer phrasing, generated takes and selection, and [music/README.md](../../music/README.md)
for the chosen recording’s timings and video handoff.
